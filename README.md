# Mchrive · 메카이브

플레이는 즐겁게, 기록은 자동으로.

메이플스토리 플레이 활동을 자동 기록·분석하는 Windows 데스크톱 애플리케이션입니다.

## 다운로드

[설치파일 및 업데이트](https://github.com/HJH413/Mchrive-Releases/releases)

최신 공개 설치 버전은 **1.13.3**입니다. [다운로드](https://github.com/HJH413/Mchrive-Releases/releases/latest)에서 설치 EXE를 받아 실행하세요.

릴리스가 게시되면 사용자는 `Mchrive-Setup-<버전>-x64.exe`를 내려받아 설치하면 됩니다. 함께 첨부되는 `update.json`과 `SHA256SUMS.txt`는 앱의 업데이트 및 파일 검증용입니다.

## 주요 기능

- 메이플 화면 분석과 사냥 알림·타이머
- 계정·월드별 자산 자동 기록 및 변화 그래프
- 보스 결정석·드랍 수익 기록
- 기록 보정·변경 이력·복구
- 데이터 백업·복원 및 시스템 트레이 실행
